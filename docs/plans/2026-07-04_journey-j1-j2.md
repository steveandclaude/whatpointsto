# Build plan — Generative journey, phases J1 (engine) + J2 (renderer)

Date: 2026-07-04 · Design record: `Interaction-Design-2026-07.md` §11 · Ruling: the journey
is Mirror's default entry (§11.5). Scope: **J1 + J2 only** — deterministic core, no probes
(J3), no LLM (J4), no content edits. Executor: background Fable fork. **No commits; no doc
edits** (the strategist reviews, records, commits, pushes — the push auto-deploys Pages so
the user can walk it on a phone).

## Contracts that must not budge

Purity: every new function is `(map, session, …) → data`; no stored journey state, no
plan objects — the horizon is a recomputed forecast. Seal: disclosure and readiness read
answers / stances / structure / structural traversal (`activeFacts`) — **never credences
or sensitivity pre-commit**. Typed moves only; no new move kinds (one additive
`SessionState` field is permitted if needed — see J1.4). Mode contracts hold: Peruse shows
the whole territory (its register); Mirror is fogged pre-commit. Words, not numbers.
PROTOCOL v1.2 for every new user-facing string. `REDUCED_MOTION` snaps all new animation.
One line per rail notch. Overlay-not-reflow for anything that expands over the scene.
Stable geography: nodes only ever appear at their home positions.

## J1 — `src/journey.ts` + `test/journey.test.ts`

1. **`neighbors(map)`** — engine-side adjacency: edge sources → effect targets (contested
   readings included), fact `bearsOn` → positions, plus whatever relations
   `web/scene.ts:buildGraph` encodes (mirror its semantics; if clean, refactor scene.ts to
   consume this so there is one source of truth — desirable, not required).
2. **`disclosure(map, session, res)`** → `{ drawn: Set<id>, frontier: string[], full:
   boolean }`.
   - `full` when session is revealed OR mode is peruse.
   - Mirror pre-commit, drawn =
     arrival outcome (no siblings; skip-arrival sessions seed from `frontier[0]` + its fed
     outcomes) ∪ answered positions + their edge-target outcomes ∪ all `activeFacts` ∪
     facts holding a stance ∪ presented facts ∪ stack origins ∪ current focus ∪ frontier.
   - `frontier` = top-K (K=2) unanswered forks adjacent to drawn territory, ranked by the
     same structural gate weight guide policy v0 uses.
   - Growth is monotone pre-commit for monotone input growth; recomputable from state
     alone at any time (post-commit, "walked" territory = disclosure recomputed as if
     unrevealed — no snapshot).
3. **`journeyOffers(map, session)`** → `GuideOffer[]` — guide policy v0's ranking wrapped
   with two journey rules: **no offer may target undrawn, non-frontier territory** (the
   guide must never leak the map), and read beats (`present-fact` for live, unpresented
   evidence bearing on recently answered forks) interleave ahead of far-frontier decide
   beats. Dispute routing and pop reminders keep their standing. Probe/rhythm logic is J3
   — leave a marked seam, do not implement.
4. **Presented-fact tracking** — check `src/session.ts`: if `present-fact` moves are not
   recoverable from `SessionState`, add an additive `presented: readonly string[]`
   (reducer case + tests). Smallest possible change; nothing else in session.ts moves.
5. **`journeyHorizon(map, session, k=3)`** → ordered stops `{ target, kind, named }`.
   Forecast semantics: take the top offer, mark it consumed (visited/presented, answers
   unchanged), re-rank, repeat k times. Deterministic status-quo forecast; stop 1 `named:
   true`, later stops shaped-only.
6. **`readiness(map, session)`** → `{ tier, copy }` from the answered fraction of total
   structural gate weight (relative, per Platform §8.5 honesty): low = "most of what your
   claim rests on is still unasked"; mid = "you've weighed some of what carries this —
   more remains"; high = "you've spoken to the load-bearing forks — committing now would
   mean something". Exact copy may be tuned; keep it assertion-shaped, no counts.
7. Export via `src/index.ts`.

**J1 tests** (node:test, joins the 76): thread seeding with and without arrival; growth on
answer (consequences drawn, frontier advances); monotonicity; seal — two maps differing
only in effect magnitudes yield identical pre-commit disclosure; offers never target
undrawn non-frontier ids; horizon reroutes when an answer changes (forecast recomputed);
readiness tier boundaries; `readiness`/new `why` strings pass `lintNarration`; purity
(same inputs → deep-equal outputs).

## J2 — the renderer wears it (`web/scene.ts`, `web/index.html`)

1. **Fog (R1)**: Mirror pre-commit renders only `drawn` — undrawn nodes/edges get an
   `undrawn` class: opacity 0, `pointer-events: none`, labels hidden, out of tab order.
   First-draw gets a pencil-in entrance (fade/scale at home position; `REDUCED_MOTION`
   snaps). Overview (focus null) shows drawn territory only; question captions only for
   questions with drawn members. Focus-frame sectors and frame chip rows render only
   drawn ∪ frontier members — the frame is fog-limited too; evidence enters via
   `present-fact` stops.
2. **Rail (R2)**: census dots deleted. Zones: trail behind (stops actually made, derived
   from `S.log` — focus/push/present-fact/answer, consecutive dupes collapsed) → here →
   horizon ahead from `journeyHorizon` (stop 1 named via `shortOf`; stops 2–3
   shaped-not-named — kind words only, e.g. "a fork", "a piece of evidence"; then a CSS
   fade — **no terminal element, no end-cap**) → promises → foot.
3. **Commit (R3)**: foot renders `readiness().copy` + the commit button (no ●○ counts
   anywhere). On commit the fog lifts: full map appears; walked territory (pre-commit
   disclosure, re-derived) inks per the existing reveal; never-walked territory renders
   in faint pencil with a distinguishable `unwalked` treatment — the "what your landing
   takes on faith" surface. Keep the §10.6 reveal-overlay open question out of scope:
   the existing overview frame is fine for now.
4. Peruse toggle: full territory, unchanged behavior. Door unchanged. Draft register
   unchanged.
